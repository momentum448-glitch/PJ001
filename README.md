# PJ001

PJ001 is a mobile-first 2D top-down action RPG prototype targeting Android, developed web-first with Phaser, TypeScript, and Vite.

## Prototype goal
Validate whether the core combat feels fun on a touchscreen before expanding content or systems.

## Current scope
- Top-down real-time action combat
- One player character
- Touch joystick + combat buttons
- Basic attack, dodge, and equipable active skills
- Small exploration/combat map
- Enemies, loot, simple level/equipment progression
- Checkpoint respawn

## Development workflow
GitHub is the source of truth. Browser builds are used for fast testing on Android; APK packaging comes later.
